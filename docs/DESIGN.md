# Design

User direction: a profile consisting only of an image containing an uncommon Leonardo quote, plus a page choosing tomorrow's quote, using the font from the ongoing portfolio revision.

Verified reference: portfolio-v2/app/layout.tsx and app/desktop/desktop.css. Exact self-hosted Terminess regular font; canvas #171c1e, ink #ede2ce, muted #aab5ae, peach accent #d79a76, rule #41585c. Bitmap monospace and dark colors preserve the user's desktop identity. Text is the primary visual, with source references and quiet numbered voting rows rather than promotional sections.

Antislop during. ENERGY 2 / RHYTHM 3 / MOTION 1. Large passage is the focal point; peach identifies actions and saved state. Whitespace separates reading from voting. The repeated notebook references and exact portfolio type establish identity. No decorative animations.

The generated concept was inspected before implementation. Necessary changes from concept: verified Richter text and correct notebook 847; real candidate passages and counts; browser voting instead of OpenAI sign-in; source/context disclosure. Desktop 1440px and mobile 390px screenshots were directly inspected for type, colors, spacing, rules, controls, wrapping, and hierarchy. Exact type makes line breaks differ from the generated approximation. No clipped text or horizontal overflow.
